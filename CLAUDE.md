# ORION — notes for Claude

ORION is a Godot 4.7 isometric pixel-art stealth and sword-duel game for a hackathon (Greek myth:
Cedalion carries the last flame through a dark temple-citadel of floating islands). Work happens on
the `v1-prototype` branch. The demo was due 2026-10-22 17:00 IST. Read `README.md`,
`docs/dev/ARCHITECTURE.md` and the top of `docs/dev/POLISH.md` (the dated log; its last entries say

## How the game is built

- Rooms come from `art/maps/rooms.json` (one character per tile) and are built in code by
  `scripts/world/room.gd`; there are no TileMaps. Tests check every room is sealed, reachable and
  usable, so keep geometry changes small and run them.
- Art loads by name through `scripts/core/art.gd`: `art/final/` overrides `art/placeholders/`
  overrides `art/greybox/`. Keep file names, sizes and pivots (feet on the bottom-centre pixel;
  tiles 32x16; blocks with their 32x16 ground diamond at the bottom).
- Most art is generated by Python tools (deterministic; re-run after changes, then `--import`).
  On a different Python or Pillow version `gen_greybox.py` redraws a few older files a pixel or
  two differently: `git checkout` those and commit only the files you meant to change. New art
  goes at the end of a generator, with its own `random.Random`, so earlier output stays the same.
  - `tools/gen_greybox.py`: tiles, walls (with the Greek frieze), floor borders, coping,
    medallions, props, HUD hearts.
  - `tools/gen_islands.py`: each room's floating island from its grid size (re-run after
    resizing a room), far islands, clouds.
  - `tools/process_sheet.py <name>`: a hand-made character sheet becomes
    `art/final/<name>_sheet.png/.json` (Aseprite format). Cedalion's boxes and sword-cut lines are
    hand-measured in the file. Any other sheet in the same layout is detected automatically.
  - `tools/animate_stills.py`: procedural sheets for the guards and Phineus (skips hand-made ones).
  - `tools/gen_swords.py` (Cedalion's swords, 32 angles), `tools/gen_audio.py`, `tools/gen_font.py`.
- Cedalion's sword is its own sprite, drawn on each frame's "hand" point (`Player._update_sword`).
  Body frames must stay sword-free. Front views face screen-right (SE), back views up-right (NE);
  the game mirrors them for the other two facings.

## Rules of the house

- Every bug fix gets a test in `tests/test_suite.gd`; keep all tests passing.
- Commit after each fix, adding files by path (never `git add -A`). Never commit `art/characters/`
  or `docs/proposal/` (Adithya's own files). Ask Adithya before pushing.
- Pixel art: the ORION palette (`art/palette/orion.gpl`), hard edges, no smoothing; light from
  the top left. Keep cracked marble, pits, water, vision cones and noise rings readable.
- v1 scope: fixed torch; guards see by lantern cone, line of sight and range; noise and
  knucklebones carry stealth; Alcyone is captive.
- Adithya prefers the main model for planning and design, with cheaper subagents (Sonnet/Haiku)
  for mechanical work such as screenshot tours and test batches.
