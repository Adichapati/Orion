## Spec: Guard (`scripts/actors/guard.gd`)

APIs other scripts already call: `grid_pos()`, `facing` (grid unit vector), `guard_id`,
`awareness`, `state`, `is_hittable()`, `is_unaware()` (not Alert), `blocks_attack_from(player_grid)`
(type.blocks_front and player within ±70° of facing and not stunned), `on_blocked(player)`,
`take_damage(dmg, from_screen_pos)`, `knock_out(env: bool, by)`, `shoved(dir8: Vector2i, by)`,
`stun_by_torch(by)`, `wants_token()` (Alert and mid-attack), `stands_on_floor()`, `is_heavy()`
(type.heavy), `fall()`.

- Setup from a rooms.json entry: `type` → `Game.guard_types`, spawn at `at`, facing `face` (grid
  vector), patrol `path` cells (cycle through them; one point = stationary, looking ±35° every 3.5 s;
  pause 1.0–1.6 s at waypoints). Collision: circle r 4.5, layer actor, mask solid|hazard|ledge|actor.
- Movement through `room.find_path()`; speeds in tiles/s from GuardType; convert with
  `Iso.grid_vel_to_screen()`. Elevation offset like the player (`room.elevation_px`).
- **Sight** (every physics frame): range `type.sight_range` (+20% "on edge" after a search, +25% when
  Alert), half-angle `type.half_angle` (Alert: at least 70°, and anything within 2 tiles); in cone and
  `room.line_of_sight()` → sees. **Awareness** rises by `(30 + 110·closeness)·delta` while seen,
  falls 12/s otherwise (not in Alert). ≥30 → Suspicious (investigate), ≥100 → Alert.
- **Hearing**: connect `NoiseBus.noise`; ignore own noises; if within radius: Alert → update last
  known; else awareness = min(95, max(awareness + 25, 35)) and investigate the noise position.
- **States**: Patrol, Suspicious (turn 0.5 s, walk to the point, look around 2.5 s, give up after 6 s
  with nothing → Return, bark "…rats."), Alert (bark "Ekei!", `Game.record_alert(guard_id)`,
  guards within 6 tiles get awareness max(+, 45) and investigate; chase via path, repath every 0.3 s;
  lose sight 3 s → Search), Search (go to last known, wander within 3 tiles for 10 s, bark "Pou?",
  then Return with `on_edge = true`), Return (path to current waypoint → Patrol), Stunned, Shoved,
  Falling, KO.
- **Combat** (Alert): keep `type.keep_distance` (Spearman backs off inside 1.2 tiles); pick an attack
  by weight whose reach covers the distance; needs `Game.request_attack_token(self)`; others circle at
  ~2 tiles. Wind-up shows `glint_white` (parryable) or `glint_red` (unparryable) over the weapon
  side and plays `glint_white`/`glint_red`; at the strike, if the player is within reach and angle:
  `player.try_parry(attack, self)` → parried (stun 0.9 s, sparks) else `player.take_hit(damage,
  global_position, knockback)`. Recover, release the token, cooldown 0.4–0.9 s.
- **Damage/KO**: flash, knockback 0.3 tiles, go Alert; hp ≤ 0 → KO: grey + tilted sprite, lantern and
  cone off, collision off, drops `randi_range(drop_min, drop_max)` obols (×1.5 if `env`) via
  `room.spawn_obols`, Watchman drops a sword via `room.spawn_sword` if `Game.weapon_id == ""`;
  `Game.stats.kos += 1` (and `env_kos` if env); `Game.release_attack_token(self)`.
- **Shoved**: move 1 tile along dir8 over 0.2 s (if the target cell is solid and not the well, stop);
  if the target is a hazard or `room.is_well(cell)` → Falling → KO(env). Otherwise stunned 0.6 s → Alert.
- **Torch thrust**: stunned for `type.thrust_stun`, then Alert.
- **Visuals**: sprite `type.sprite_se`/`sprite_ne` with flip by screen direction (as in player.gd);
  lantern = PointLight2D (`light_cone`, colour `type.lantern_color`) inside a pivot scaled (1, 0.5),
  rotated to `atan2(sd.y*2, sd.x)` where `sd = Iso.screen_dir(facing)`; texture_scale =
  range·22.6/64. Vision cone polygon drawn on `room.cone_layer` (z −60, additive, alpha ~0.15 calm,
  yellow when Suspicious, red when Alert), 16 rays shaped with `room.ray_end()`. `mark_question` /
  `mark_alert` sprite over the head plus a thin awareness meter. Barks through
  `Game.floating_text.emit(pos, text, colour)`.

## Spec: main scene (`scripts/main.gd`)

- Node tree: `Main` (Node) → `WorldContainer` (SubViewportContainer, full rect, `stretch = true`,
  `stretch_shrink = 2`, texture_filter nearest) → `WorldViewport` (SubViewport 480×270) → the Room;
  `UI` (CanvasLayer) for every Control in 960×540 space.
- Flow: title → intro cards → `load_room(Game.room_index)` → … → end card. A room = `Room.new()`,
  `build(Game.rooms[i])`, spawn guards, spawn the Player at `room.player_spawn`, set
  `player.room`, `room.player`, camera limits from `room.bounds()`, show the room-name banner,
  `Sfx.start_music()`.
- `room.exit_reached` → `Game.take_snapshot()`, next room (after the last: `Game.finish_run()` → end
  card). `player.died` → death message → `Game.restore_snapshot()` → rebuild the same room.
  `room.message("shop")` → `player.lock(true)` → shop panel (buy/equip, prophecy line, "Save" =
  `Game.take_snapshot()`) → unlock.
- Every frame: `Sfx.set_tension(max guard awareness / 100)`; project world points to UI with
  `world_viewport.get_canvas_transform() * p * 2.0`.
- Pause on Esc (`get_tree().paused`, UI `process_mode = ALWAYS`). F3 toggles `Game.set_debug_overlay`.
